# 🍉 合成大西瓜 - 中文版

一个超好玩的物理合成游戏！两个相同的水果碰撞会合成更大的水果，从葡萄一路合成到西瓜！

## 🎮 怎么玩？

1. 移动鼠标控制位置
2. 点击掉落水果
3. 两个相同的水果碰撞会合成更大的水果
4. 水果堆超过顶部线就游戏结束

## 🍇 水果合成顺序

葡萄 → 樱桃 → 橘子 → 柠檬 → 苹果 → 桃子 → 菠萝 → 西瓜

## ✨ 特点

- 纯 HTML5 + JavaScript 实现
- 不需要安装，打开浏览器就能玩
- 手机电脑都能玩
- 完全免费，开源
